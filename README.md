# qianjin-book-deconstruct

把**任意一本书**拆解成一套可迁移、可践行的**核心知识学习体系**的 WorkBuddy 技能。

> 原为 `book-deconstruct`，现以 `qianjin-` 前缀发布于 ZOORO-NEW，与本地技能命名保持一致。

## 能拆什么

国学 / 哲学经典、商业方法论、心理认知、科学科普、历史传记、自助成长、技术书籍——同一套八段式骨架，只是「映射镜头」随书而变。

## 八段式输出

1. **一句话内核** —— 固定句式，必须可证伪，不写空话
2. **系统地图** —— 全书归纳成 5–9 个可独立练习的模块
3. **核心要点提炼** —— 8–15 条原文金句 / 关键论点，每条映射到现代应用场景
4. **术语 / 概念速查表** —— 10–20 张卡，含「原典涵义 / 现代语境 / **常见误读**」
5. **可带走的行动原则** —— 5–10 条，每条带「适用场景 + 反模式」
6. **小节拆解** —— 每个模块展开：内核 / 关键要点 / 应用场景 / 微行动 / 自检问题
7. **21 天践行路线** —— 按阶段排进时间线的少而践行计划
8. **边界与延伸** —— 说清「这本书不解决什么」+ 互补书单

## 安装

```bash
git clone https://github.com/ZOORO-NEW/qianjin-book-deconstruct.git ~/.workbuddy/skills/qianjin-book-deconstruct
```

重启 WorkBuddy 后，在对话中直接说书名即可，例如：

- 「把《思考，快与慢》拆成认知体系」
- 「《人类简史》拆成规律与借鉴」
- 「《代码大全》给我可学的知识体系」
- 「《习惯的力量》拆成践行清单」

## 把手册渲染成 HTML

```bash
python scripts/render.py 你的手册.md -o 你的手册.html
```

生成的 HTML 自带左侧目录导航、术语表格与章节锚点，可直接系统化学习或分享。

## 文件结构

- `SKILL.md` —— 触发条件与七步拆解工作流 + 固定输出骨架
- `references/method.md` —— 完整方法论 + 《道德经》(国学镜头) 与《原则》(商业镜头) 双范例
- `assets/output-template.md` —— 填空式骨架，复制即填
- `scripts/render.py` —— Markdown 手册 → 带目录的独立 HTML（零依赖）
